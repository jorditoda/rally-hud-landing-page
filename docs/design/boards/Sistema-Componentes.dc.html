En Flutter

ColoresColorScheme.dark y ColorScheme.light con cy como primario y er como error. Verde, naranja, violeta y ámbar en un ThemeExtension<RallyColors>.
TipografíaTextTheme con Barlow y Barlow Condensed.
CifrasFontFeature.tabularFigures() en todo estilo numérico, dentro de un NumericText.
BotonesFilledButton (alto mínimo 56), OutlinedButton y TextButton, definidos en el tema.
Chips y selectorChoiceChip y SegmentedButton.
CamposInputDecorationTheme: relleno s1, borde ln, enfocado cy, error er.
TarjetasCardTheme (CardThemeData desde Flutter 3.27) con radio 16, sin elevación y borde ln.
NavegaciónNavigationBar con cinco destinos.
Fila de rankingWidget propio RankingRow (rango, nombre, tiempo, delta, resaltado).
InsigniasWidget propio StatusPill con color y texto.
Velocímetro y tablaText con FittedBox y una barra propia; ListView con RankingRow. Sustituyen a syncfusion_flutter_gauges y datagrid.
Gráficos y mapaSe mantienen fl_chart y flutter_map. Los gráficos ya escritos se reutilizan en el tablero 19.
Fuentes dentro de la appEmpaquétalas como assets en lugar de descargarlas con google_fonts. En un tramo de rally puede no haber cobertura, y la primera descarga fallaría justo ahí.
Quitar Syncfusion es opcionalEl diseño no lo necesita, pero no depende de quitarlo: se puede hacer al final, pantalla a pantalla.
// lib/theme/rally_colors.dart (esquema)
class RallyColors extends ThemeExtension<RallyColors> {
  const RallyColors({required this.record, required this.warning,
      required this.lateralG, required this.pending});
  final Color record, warning, lateralG, pending;
  // copyWith y lerp, como pide ThemeExtension
  static const dark = RallyColors(
    record: Color(0xFF4ADE80), warning: Color(0xFFFF7A45),
    lateralG: Color(0xFFB794FF), pending: Color(0xFFFFC247));
  static const light = RallyColors(
    record: Color(0xFF0E7C3A), warning: Color(0xFFC2410C),
    lateralG: Color(0xFF6D3FD4), pending: Color(0xFF8A5A00));
}
